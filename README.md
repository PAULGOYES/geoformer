# GeoFormer

GeoFormer is a Transformer-based framework for landslide susceptibility mapping using trainable categorical embeddings. The repository contains the implementation, experiments, trained models, and notebooks used in the study.

## Repository Structure

```
GeoFormer/
│
├── trained_models/                                   # Saved trained models
├── DataPaul.xlsx                                     # Dataset used in the experiments
│
├── GeoFormer_20random_model_training.ipynb           # Training and evaluation over 20 random stratified splits
├── GeoFormer_B_baseline_encoding_strategies_.ipynb   # Comparison of categorical encoding strategies
├── GeoFormer_attention_heads_comparison.ipynb        # Ablation study on the number of attention heads
├── GeoFormer_probability_analysis.ipynb              # Probability distribution and susceptibility analysis
│
├── LICENSE
└── README.md
```

## Overview

GeoFormer introduces a trainable embedding layer specifically designed for categorical conditioning factors in landslide susceptibility mapping. Instead of relying on fixed encoding schemes such as one-hot or ordinal encoding, the proposed architecture learns task-specific representations that are optimized jointly with the Transformer model.

The repository includes:

- Complete implementation of GeoFormer.
- Training notebooks.
- Ablation experiments.
- Probability map analysis.
- Trained models for reproducibility.

## Notebooks

### 1. GeoFormer_20random_model_training.ipynb

Main notebook used to train and evaluate GeoFormer over multiple random stratified train-test splits. Performance metrics are computed to evaluate robustness and generalization.

---

### 2. GeoFormer_B_baseline_encoding_strategies_.ipynb

Compares different categorical encoding strategies, including conventional encodings and the proposed trainable embedding layer.

---

### 3. GeoFormer_attention_heads_comparison.ipynb

Ablation study evaluating the influence of different numbers of Transformer attention heads on model performance.

---

### 4. GeoFormer_probability_analysis.ipynb

Analyzes predicted probability distributions and susceptibility maps generated by the trained models.

## Requirements

The notebooks were developed using **Python 3.10+** and the following libraries:

- PyTorch
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- OpenPyXL
- Google Colab (optional, for running the notebooks in Colab)

Install the required packages with:

```bash
pip install torch numpy pandas matplotlib scikit-learn openpyxl
```

If you plan to run the notebooks locally, you can ignore the `google.colab` import or remove it. When using Google Colab, all required packages are already available except any additional packages you may install manually.
